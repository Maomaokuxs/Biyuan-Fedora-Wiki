# 说明

提供一些模板，方便手动创建桌面快捷方式，以及排查快捷方式不显示或无法启动的问题。

## 快捷方式存放位置

| 位置 | 作用域 | 说明 |
| ------ | -------- | ------ |
| `/usr/share/applications/` | 所有用户 | 系统级，需 `sudo` |
| `~/.local/share/applications/` | 当前用户 | 用户级，同名覆盖系统级 |
| `~/桌面/` 或 `~/Desktop/` | 当前用户 | 放在桌面上，允许双击执行 |

优先级：`~/桌面/` > `~/.local/share/applications/` > `/usr/share/applications/`

## .desktop 文件格式

```desktop
[Desktop Entry]
Version=1.0
Type=Application
Name=应用名称
Exec=/path/to/binary
Icon=图标名或路径
Comment=鼠标悬停时的提示文字
Categories=Development;IDE;
Terminal=false
```

### 常用字段

- **Type**：`Application`（普通应用）、`Link`（快捷方式）、`Directory`（目录）
- **Exec**：可执行文件路径，支持 `%f`（单个文件）、`%F`（多个文件）、`%u`（单个 URL）等参数
- **Icon**：可以是路径（`/opt/app/icon.png`）或图标名（`firefox`，从系统图标主题查找）
- **Categories**：分类，影响应用菜单中的位置，常用值见下
- **Terminal**：`true`（显示终端）或 `false`（不显示）
- **StartupWMClass**：用于窗口管理器分组，防止 Dock 上出现两个图标
- **MimeType**：关联的文件类型，如 `text/plain;image/png;`
- **StartupNotify**：`true` 或 `false`，是否显示启动反馈

### Categories 常用值

| 分类 | 适用场景 |
| ------ | --------- |
| `Development;IDE;` | 开发工具、IDE |
| `Development;` | 开发者工具 |
| `Network;InstantMessaging;` | 通讯软件 |
| `AudioVideo;Player;` | 播放器 |
| `Graphics;` | 图像处理 |
| `Utility;` | 实用工具 |
| `Game;` | 游戏 |
| `Office;` | 办公软件 |
| `System;` | 系统工具 |

## 常见示例

- **tar.gz 应用（解压到 /opt/）**

```desktop
[Desktop Entry]
Version=1.0
Type=Application
Name=MyApp
Exec=/opt/myapp/myapp
Icon=/opt/myapp/icon.png
Comment=应用描述
Categories=Utility;
Terminal=false
```

- **AppImage**

```desktop
[Desktop Entry]
Type=Application
Name=MyApp
Exec=/opt/myapp/MyApp-x86_64.AppImage
Icon=/opt/myapp/icon.png
Categories=Utility;
Terminal=false
```

- **Java 应用（jar）**

```desktop
[Desktop Entry]
Type=Application
Name=HMCL
Exec=java -jar /opt/hmcl/HMCL.jar
Icon=/opt/hmcl/icon.png
Categories=Game;
Terminal=false
```

- **终端脚本**

```desktop
[Desktop Entry]
Type=Application
Name=My Script
Exec=/home/user/script.sh
Terminal=true
Categories=Utility;
```

## 刷新图标缓存

```bash
# 用户级
update-desktop-database ~/.local/share/applications/ 2>/dev/null

# 系统级
sudo update-desktop-database /usr/share/applications/
sudo gtk-update-icon-cache /usr/share/icons/hicolor/
```

登出重新登录，或直接杀掉桌面进程重进即可看到变化。

## 让桌面文件可双击执行

放在 `~/Desktop/` 下的 `.desktop` 文件需要可执行权限才能双击运行：

```bash
chmod +x ~/Desktop/myapp.desktop
```

GNOME 可能还需要在文件管理器中右键 → 允许启动，或在终端运行：

```bash
gio set ~/Desktop/myapp.desktop metadata::trusted true
```

## 排查技巧

| 现象 | 原因 | 解决 |
| ------ | ------ | ------ |
| 快捷方式不显示 | 目录不对或 Categories 没分类 | 放到 `~/.local/share/applications/` 并刷新缓存 |
| 点击没反应 | Exec 路径错误或权限不足 | 确认路径是否存在，文件是否可执行 |
| 图标不显示 | Icon 路径错误或格式不对 | 使用绝对路径，PNG 或 SVG 格式 |
| Dock 上出现两个图标 | 缺少 StartupWMClass | `xprop WM_CLASS` 获取窗口类名后填入 |
| 文件管理器不识别 | 缺少可执行权限或 GNOME 信任标记 | `chmod +x` 并 `gio set ... trusted true` |

### 获取 StartupWMClass

```bash
# 先启动应用，然后运行
xprop WM_CLASS

# 点击应用窗口，输出类似：
# WM_CLASS(STRING) = "jetbrains-idea", "jetbrains-idea"
```

取第二个值填入 `StartupWMClass=jetbrains-idea`。

## 符号链接方式

.dekstop 文件还可以通过符号链接实现一份文件多处出现，但链接的目标必须存在。

```bash
ln -s /usr/share/applications/firefox.desktop ~/桌面/
```
