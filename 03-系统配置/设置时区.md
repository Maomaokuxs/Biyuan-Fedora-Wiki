# 说明

因为我在看论坛或者评论区的时候有一些问题是因为设置时区有漏洞，导致不能够安装系统，那么就可以不先设置时区，在安装完之后再重新更改。

不只是可以在 fedora 上使用，使用了systemd管理系统服务，一般都能适用。

## 1.查看当前设置

```bash
timedatectl
```

## 2.列出所有可用的时区

```bash
timedatectl list-timezones

# 使用grep 筛选
timedatectl list-timezones | grep Shanghai
```

## 3.设置新时区 使用以下命令修改（需要管理员权限）

```bash
sudo timedatectl set-timezone Asia/Shanghai
```

将 Asia/Shanghai 替换为你需要的时区即可。

## 4. (可选) 执行以下命令将 RTC 改为 UTC 模式

```bash
sudo timedatectl set-local-rtc 0
```

1. UTC（协调世界时，Coordinated Universal Time）

    国际时间标准，全球统一，不受时区和夏令时影响。所有时区的本地时间都是基于 UTC 偏移得到的（如 UTC+8 表示比 UTC 快 8 小时）。

    在系统中：Linux 内核维护的系统时间通常使用 UTC（即使你看到的是本地时间，底层也是 UTC，只是应用程序根据时区设置做了转换）,在 Fedora 中默认安装似乎使用的是 RTC，大概是考虑与 Windows 系统时间同步，需要满足这种需求默认设置而不修改，如果想双系统设置为 UTC，可以看[解决与Windows系统共存的问题](../06-一些问题/解决与Windows系统共存的问题.md)。

2. RTC（实时时钟，Real-Time Clock）

    计算机主板上的硬件时钟，由独立电池（如纽扣电池）供电，即使电脑关机、断电也能持续运行。

    在系统中：RTC 保存着时间信息，系统启动时会读取 RTC 来初始化系统时间；关机时也可能将系统时间写回 RTC。

3. 两者在 Linux 中的关系

    - 系统启动时：从 RTC 读取时间，根据配置决定如何解释。

        若 RTC 设置为 UTC：将 RTC 时间直接作为 UTC 使用，再结合时区计算出本地时间。

        若 RTC 设置为 本地时间：将 RTC 时间视为本地时间，再反向推导出 UTC。

    - 系统运行中：内核维护的系统时间始终是 UTC 格式，所有时间计算基于此。

    - 关机时：可以选择将当前系统时间（UTC）写回 RTC。

## 5.校准一次硬件时钟

```bash
sudo hwclock --systohc
```

这会用当前系统时间（UTC）更新硬件时钟。
