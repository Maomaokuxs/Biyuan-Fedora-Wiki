# 说明

本片文档旨在说明成员管理。

## 0.软件包

通常不需要安装对应的软件包。

## 1.使用 usermod

```bash
usermod -aG \[组名] \[添加的成员]
```

## 2.将普通用户加入 wheel 组

fedora 默认将第一个创建的普通用户添加至 wheel 组，在 /etc/sudoers 文件中定义了能够使用 sudo 命令的组，默认为 %wheel ALL=(ALL) ALL，这一行允许 wheel 组的成员从任何主机 (ALL) 以任何用户身份 (ALL) 执行任何命令 (ALL)。

```bash
sudo usermod -aG wheel biyuan
# 将 biyuan 加入 wheel 组
```
